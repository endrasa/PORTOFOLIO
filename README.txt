ENDRA SAPUTRA — IT PORTFOLIO FULL
====================================

Folder ini adalah versi lengkap dari HTML portfolio yang Anda upload.

STRUKTUR:
index.html
  Halaman lengkap portfolio: Home, About, Skills, Experience, Projects,
  Certifications, Portfolio/Gallery, Education/Career, Contact, Footer, dll.

css/style.css
  Semua CSS asli, tema dark/blue, animasi 3D, responsive dan efek visual.

js/main.js
  JavaScript asli yang ada di HTML dipisahkan ke sini, ditambah helper
  mobile menu, navbar scroll dan reveal animation.

assets/
  Gambar embedded/base64 dipisahkan menjadi file lokal.

original_portfolio.html
  Backup file HTML asli.

CARA EDIT:
1. Buka folder ini di VS Code.
2. Edit teks/isi website di index.html.
3. Edit warna, ukuran, layout dan animasi di css/style.css.
4. Edit interaksi di js/main.js.
5. Ganti foto/logo/gambar di assets/.
6. Buka index.html dengan Chrome/Edge.

Semua section dari HTML sumber dipertahankan; file hanya dipisahkan
menjadi HTML + CSS + JS + assets agar lebih mudah diedit.
